2. Presentación

En el dinámico mercado laboral de las Industrias 4.0, las organizaciones demandan soluciones altamente accesibles y conectadas que operen en tiempo real a través de la web y de dispositivos móviles. Tras superar la fase de diseño arquitectónico, este es el momento cumbre donde los requerimientos técnicos y los modelos lógicos se transforman en código fuente funcional.

Escribir código de alta calidad requiere la aplicación rigurosa de saberes técnicos como el Paradigma Orientado a Objetos, uso de lenguajes modernos (Java, Python, PHP, C#, Ruby), manejo de Frameworks, Servicios Web (REST/SOAP) y protocolos de seguridad para mitigar amenazas como el SQL Injection.

Resultados que integran la competencia:
  • [01] Planear actividades de construcción
  • [02] Construir la base de datos
  • [03] Crear componentes front-end
  • [04] Codificar el software de acuerdo con el diseño establecido (Enfoque de esta guía)
  • [05] Realizar pruebas al software

5. Glosario de Términos

10 Conceptos

API (Application Programming Interface)

Conjunto de definiciones y protocolos que permite comunicación entre aplicaciones mediante estándares como REST o SOAP.

Blockchain

Registro distribuido e inmutable que asegura transacciones auditables y resistentes a la manipulación.

Cloud Computing

Servicios de computación, almacenamiento y software elásticos accesibles por internet.

Control de Versiones (GIT)

Sistema para gestionar cambios en el código, asegurando trazabilidad y trabajo colaborativo.

Framework

Estructura reutilizable con patrones de diseño para agilizar la construcción de software.

SQL Injection

Vulnerabilidad de seguridad provocada por inserción de código SQL malicioso en entradas de datos.
